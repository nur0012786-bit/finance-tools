# Finance Tools — US Mortgage Growth & Revenue Plan

Updated: 2026-09-29

## Current position

The repository is already a US-focused finance calculator hub with 25 calculators, mortgage guides, trust pages, sitemap/robots files, Google Analytics 4, and a live Mortgage Calculator page.

The strategic mistake to avoid is trying to make the mortgage page earn money before it earns search demand. The sequence is:

**Useful calculator → search visibility → repeatable organic traffic → compliant ad monetization → higher-value ad stack.**

Do not buy traffic, incentivize ad clicks, use bots, scrape competitors, or publish large numbers of thin AI pages.

## 2. SEO strategy

### Primary intent

Target calculator intent first:

- mortgage calculator
- mortgage payment calculator
- home loan calculator
- monthly mortgage payment calculator
- mortgage payment estimator
- mortgage calculator with taxes
- mortgage calculator with PMI
- mortgage calculator with HOA
- mortgage calculator with insurance
- mortgage amortization calculator

One third-party keyword dataset currently reports very large US demand for the head term, but keyword-tool numbers are estimates rather than guaranteed traffic. Treat them as demand signals, not forecasts.

### Long-tail strategy

Build pages only when the page has a distinct user intent and materially useful functionality/content.

Examples:

- 30 year mortgage calculator
- 15 year mortgage calculator
- mortgage payment on $300,000
- mortgage payment on $400,000
- mortgage payment on $500,000
- mortgage calculator with property tax
- mortgage calculator with PMI
- mortgage affordability calculator
- mortgage refinance break-even calculator
- mortgage points break-even calculator

Do NOT create hundreds of nearly identical pages by swapping only a number. That creates a thin programmatic site and is exactly the kind of scalable low-value content Google is increasingly designed to suppress.

### State/local expansion

Only create state pages when you can add real local value:

- state property-tax assumptions/data
- state-specific home-buying costs
- useful local explanations
- links to authoritative state/county resources
- clearly dated methodology

Do not make 50 pages that all say the same thing with a state name inserted.

## 4. Authority strategy

The highest-value backlinks are not random SEO links. Prioritize:

1. Real-estate and home-buying publications
2. Housing/finance educational sites
3. Local real-estate professionals with genuine resources
4. Personal-finance newsletters
5. Universities/nonprofit financial education resources where appropriate
6. Original-data citations when the site publishes useful calculations or research
7. Relevant communities where sharing the tool genuinely answers a question

Pitch the calculator as a free utility, not as "please give me a backlink."

Create one linkable asset each quarter, such as:

- Mortgage payment comparison dataset
- Historical rate/payment impact calculator
- Closing-cost comparison study
- First-time buyer cost worksheet
- Mortgage affordability methodology report

## 5. Technical SEO

Maintain:

- One canonical URL per page
- Clean internal links
- XML sitemap
- robots.txt
- Fast mobile rendering
- Accessible labels and contrast
- No intrusive popups
- Valid HTML
- Descriptive titles/meta descriptions
- Breadcrumbs where useful
- Structured data only when it accurately describes the page
- Search Console monitoring
- GA4 event tracking

Do not obsess over a perfect Lighthouse score while ignoring useful content and search intent. Google states that Core Web Vitals are ranking signals, but good scores alone do not guarantee top rankings.

## 6. Revenue architecture

### Stage A — before meaningful traffic

Do not clutter the site with aggressive ads.

Focus on:

- calculator completion rate
- organic impressions
- organic clicks
- returning users
- pages/session
- calculator-to-guide clicks
- top landing pages
- US/UK/Canada traffic mix

### Stage B — AdSense

Once the site is eligible and approved:

- add the required AdSense code correctly
- test Auto ads conservatively
- exclude the calculator input/result areas from confusing ad placements
- keep ads visually distinct from buttons and calculator controls
- never ask users to click ads
- never reward ad clicks
- never buy low-quality traffic

Google explicitly prohibits encouraging accidental clicks and recommends considering the user's task when placing ads.

For a calculator page, the calculator itself is the product. Ads should not look like calculator buttons.

### Stage C — higher-value ad management

Current published Mediavine requirements say Journey starts at 1,000 sessions from Tier 1 countries in a 30-day period, while the main Mediavine program requires at least $5,000 in annual ad revenue and quality/traffic standards.

Raptive currently lists 25,000 monthly pageviews as its minimum, plus traffic-quality, content, analytics and domain-age requirements for the 25k–99,999 pageview tier.

Requirements change. Re-check official publisher requirements immediately before applying.

## 7. Domain strategy

The GitHub Pages URL is useful for development and initial indexing, but the commercial asset should eventually use a custom domain.

Before serious monetization/outreach:

- acquire a short, brandable domain
- move GitHub Pages behind the custom domain
- configure HTTPS
- set one canonical host
- redirect the alternate host
- update canonical URLs, sitemap and Search Console
- keep the same URL structure where possible

Do not buy a domain just because it contains "mortgage calculator." A brand that can later support calculators, guides and other home-finance tools is more defensible.

## 9. The real growth loop

The growth loop should be:

Search query
→ useful calculator
→ result
→ related calculator
→ guide
→ another calculator
→ return visit
→ ad impression
→ more search visibility from improved engagement and links.

The site should not depend on one giant keyword. It should own a cluster of closely related mortgage tasks.

## 10. What NOT to do

- No bot traffic
- No click exchanges
- No paid "SEO traffic" packages
- No incentivized ad clicks
- No fake reviews/testimonials
- No copied lender content
- No mass AI-generated pages with tiny variations
- No fake current mortgage rates
- No pretending the calculator is a lender
- No unsupported claims like "guaranteed savings"
- No deceptive ad placements
- No keyword stuffing
- No 50 state pages with no unique value

## Bottom line

The "hack" is not a trick.

The defensible advantage is a better mortgage planning tool + better explanations + better internal linking + trustworthy methodology + real US search demand + clean monetization.

That is slower than publishing 500 AI pages, but it creates an asset that can survive search-quality changes and attract higher-value finance traffic.
